# TeleRec Android

Android phone app for TeleRec: a Garmin watch is the remote start/stop button and photo shutter, the phone records.
It talks to the unchanged watch app in [telerec-garmin](https://github.com/dotnetthai/telerec-garmin) with the same wire protocol as
the [iOS app](https://github.com/dotnetthai/telerec-ios).

Status: planning only, no code yet. See [PLAN.md](PLAN.md).
